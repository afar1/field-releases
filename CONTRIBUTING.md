# Contributing to Field Theory Release Feed

This repository is for packaged Field Theory Mac release artifacts and updater metadata.

Use issues here only for installer, download, updater-feed, or release-artifact problems.

Use the source repositories for source changes:

- [`afar1/fieldtheory`](https://github.com/afar1/fieldtheory): Field Theory Mac app source.
- [`afar1/fieldtheory-cli`](https://github.com/afar1/fieldtheory-cli): Field Theory CLI.
- [`afar1/fieldtheory-plugin`](https://github.com/afar1/fieldtheory-plugin): Field Theory Codex plugin and skills.

Do not submit app source code, production Supabase schema, migrations, Edge Functions, Cloud infrastructure, billing internals, service configuration, secrets, or private operational runbooks to this repository.
